Réglages

Comment obtenir la clé (gratuit, 5 minutes)
  1. Va sur console.cloud.google.com avec un compte Google et crée un projet.
  2. « API et services » → « Bibliothèque » → cherche Books API → Activer.
  3. « Identifiants » → « Créer des identifiants » → « Clé API », puis copie-la ici.
Comment obtenir la clé (quelques centimes par catalogue)
  1. Va sur console.anthropic.com et connecte-toi (compte distinct de claude.ai).
  2. Settings → Billing : achète du crédit (5 $ suffisent pour des années).
  3. Settings → API Keys → Create Key : copie la clé tout de suite (elle ne s'affiche qu'une fois) et colle-la ici.
