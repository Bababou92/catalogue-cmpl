Comment obtenir la clé (gratuit, 5 minutes)
  1. Va sur console.cloud.google.com avec un compte Google et crée un projet.
  2. « API et services » → « Bibliothèque » → cherche Books API → Activer.
  3. « Identifiants » → « Créer des identifiants » → « Clé API », puis copie-la ici.
